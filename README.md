## 执行原则

1. 雅思是硬性条件，每天优先完成。
2. 两个完整项目胜过多个半成品。
3. 可以使用 Codex 辅助，但必须理解并能解释核心代码。
4. 项目不得公开客户姓名、电话、地址、密码、密钥或真实订单数据。
5. 每天记录成果，不用“学习了很久”代替可验证的产出。
6. 每周复盘一次；若进度落后，先缩减功能，不牺牲雅思和申请材料。
