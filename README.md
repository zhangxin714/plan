# 我的个人计划中心

欢迎来到我的计划仓库。这里用来记录目标、安排任务和保存想法。

## 近期重点

- [ ] 写下本月最重要的 3 个目标
- [ ] 把目标拆成可以完成的小任务
- [ ] 每周回顾一次进度

## 使用方法

1. 点击文件右上方的铅笔图标进行编辑。
2. 把示例内容替换成自己的内容。
3. 完成任务后，把 `[ ]` 改成 `[x]`。
4. 在页面底部填写修改说明，然后点击绿色按钮保存。

> 不必一次写得很完整。先记录一件真正想完成的事，就已经开始了。
